## =' Technical Architecture

### Service Composition Pattern
The RouteAssignmentService acts as the main orchestrator, composing all Layer 2 services:
```cpp
RouteAssignmentService::setServices(
    DatabaseManager* dbManager,
    GraphService* graphService,           // A* pathfinding
    ResourceLockService* resourceLockService, // Conflict management  
    OverlapService* overlapService,       // Safety overlaps
    TelemetryService* telemetryService,   // Performance monitoring
    VitalRouteController* vitalController // Safety validation
);
```

### Route Processing Pipeline
1. **Validation** � VitalRouteController validates safety requirements
2. **Pathfinding** � GraphService finds optimal A* path with point machine conditions
3. **Overlap Calculation** � OverlapService determines safety braking distances
4. **Resource Reservation** � VitalRouteController locks resources safely
5. **Finalization** � Database persistence and overlap reservation

### Route State Machine
`REQUESTED � VALIDATING � RESERVED � ACTIVE � PARTIALLY_RELEASED � RELEASED`

### Safety Levels
`VITAL_SAFE � SAFE � CAUTION � WARNING � DANGER`
